Sözly Mobile Application Privacy Policy

Version 1, October 10, 2026

1. General Provisions

1.1. This policy describes what data the Sözly application processes and how it is protected. The operator is Bahrom Saliev (the "Operator", also the "Rightholder").

1.2. This policy takes into account the Law of the Republic of Uzbekistan "On Personal Data".

1.3. Main principle: the application requires no registration and does not collect the User's name, phone number, email or any other data that could identify the User. Learning data is stored only on the User's device and is not sent to the Rightholder.

2. What Data Is Processed

Data Where it is stored Why
Interface language, settings, daily goal, reminder time On the device only Running the app as the User chose
Word learning progress, statistics, day streak On the device only Spaced repetition and statistics
The User's own words and categories On the device only Personal dictionary
Premium and trial status On the device; purchase confirmation in the app store Access to paid features
IP address and technical request data (device type, time) With content delivery service providers Loading the dictionary and images

3. Third-Party Services

3.1. Google Play / App Store process payments and confirm purchases. The Rightholder does not receive card numbers or other payment details.

3.2. Google (Google Sheets, Google Fonts), GitHub and jsDelivr are used to load dictionary updates, images and fonts. When loading, these services receive the device's IP address and technical request data and process them under their own privacy policies.

3.3. Word pronunciation is produced by the device's built-in speech synthesizer according to its settings.

3.4. The application does not use advertising, advertising identifiers or analytics services.

4. Notifications

4.1. The application sends local study reminders only after the User grants permission. Reminders are created on the device itself, without sending data to a server.

4.2. Reminders can be turned off in the application settings or in the device's system settings.

5. Data Storage and Deletion

5.1. Data is stored on the device while the application is installed.

5.2. Deleting the application deletes learning data and the User's own words from the device. If system backup (Google or iCloud) is turned on, the operating system may keep them in the User's backup and restore them on reinstall. The Rightholder has no access to that backup. A paid subscription status is kept in the app store and can be restored with the "Restore purchases" button.

6. Data Sharing

The Rightholder does not sell, rent or share the User's data with third parties, except as described in Section 3 and as expressly required by the laws of the Republic of Uzbekistan.

7. Children

The application is intended for users aged 13 and over. Users under 13 may use the application with the consent and supervision of their parents. The application does not collect personal data from children.

8. Security

Data is protected by the device's operating system. Connections to content delivery services use the secure HTTPS protocol.

9. User Rights

The User may request information about data processing, revoke notification permission, and delete their data by deleting the application. Questions can be sent to the email below.

10. Policy Changes

When the policy changes, the application shows the new version with its number and date. If the application starts processing new kinds of data, the User will be notified before such processing begins.
